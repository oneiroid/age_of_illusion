# Quote

An italic display quotation with a mono source line, for epigraphs, testimony and dictated notes; it can carry a reversed echo and a ghost double.

- Provide the words as `children` without quotation marks, and `source` in lowercase ("tape 14, side b, 03:47").
- `echo` adds a faint mirrored copy of the line reversed letter by letter, as if the room said it back. Use it on one quote per page.
- `ghost` splits the line into a red and a magenta double. Do not combine `ghost` with a `display-xl` title on the same screen.
- `size="l"` is for an epigraph that opens a page. Keep the body under 30 words.
